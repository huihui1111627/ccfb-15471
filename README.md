# 多模型级联推理服务仿真

客服问答 + 内容审核场景的三级模型级联(小→中→大)仿真:用小模型先答,
没把握逐级升级,在成本预算下最大化准确率,并在数据漂移时自动重校准。

## 运行

```bash
python3 run_experiment.py
```

约 30 秒跑完,结果在 `output/`:`report.html`(完整报告)+ 各张 PNG 图。

## 模块

| 文件 | 内容 |
|---|---|
| `cascade_sim/data.py` | 仿真请求流:20 个类别先验不均衡、每类难度不同、25% 边界难样本;第 10 天起类别先验/特征空间/难度漂移 |
| `cascade_sim/models.py` | NumPy 实现的小/中/大分类网络(6 维线性 / 12 维+32 隐层 / 40 维 320x160,成本 1/8/60)、MC-dropout 多次随机推理、升级判别器(逻辑回归) |
| `cascade_sim/calibration.py` | 温度缩放、等频分箱校准、ECE、可靠性曲线 |
| `cascade_sim/cascade.py` | 级联评估与阈值网格搜索(预算下最优准确率 / 目标准确率下最低成本) |
| `cascade_sim/service.py` | 在线服务:批处理+升级重组批、前级结果复用、抽查监控、周期重校准(三份交叉拟合 + 滞回采纳) |
| `cascade_sim/report.py` | 绘图与 HTML 报告生成 |
| `run_experiment.py` | 端到端实验:训练→校准→阈值搜索→判别器→30 天流式评估→报告 |
| `tune_models.py` | 开发用:模型分层准确率快速检查 |

## 实验结论(仿真数据)

- 校准+阈值搜索级联:准确率 ~0.85,成本仅为全部大模型的 ~15%
- 固定阈值(未校准)级联明显更差,说明校准是级联的前提
- 判别器与校准置信度同预算下相当,可作为不依赖校准的备用升级信号
- 分布漂移后静态级联 SLA 失守(~0.80);抽查监控 + 周期重校准
  (交叉拟合防过拟合、滞回采纳防抖动)使 SLA 自动恢复,成本仍远低于全部大模型
